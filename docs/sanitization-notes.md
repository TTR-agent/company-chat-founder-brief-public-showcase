# Sanitization Notes

This repo is a public-safe mirror of a private operating pattern.

## Preserved

- The architecture: chat input -> normalization -> person/workstream analysis -> founder voice rendering -> daily and weekly outputs.
- The evidence-first rule: visible chat evidence must be separated from interpretation.
- The visibility-gap rule: if there is too little evidence, the output says so.
- The founder voice concept: meeting prep should sound like the founder, not like generic corporate reporting.
- The managerial/commercial framing: the output focuses on ownership, blockers, customer/revenue implications, and next actions.

## Replaced

- Real Slack messages were replaced with fake examples.
- Real people were replaced with sample names.
- Real channels were replaced with generic `company-chat`.
- Private founder voice guidance was replaced with a public-safe voice profile.
- Live Slack connector details were removed.

## Removed

- API tokens and credentials.
- Private Slack channel IDs.
- Real names, companies, customers, or internal project details.
- Raw logs or transcripts.
- Any delivery automation that would post to Slack.
